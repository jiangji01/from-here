## Release structure

Create tag:

`v1.1.0`

The public macOS asset is built by `.github/workflows/release.yml`, not by hand. The workflow:

1. builds pinned target-native Node + `@music163/ncm-cli` runtimes on Apple Silicon and Intel macOS runners;
2. assembles one universal `From-Here-v1.1.0-macOS.zip`;
3. runs deterministic recommendation tests;
4. boots the exact ZIP on both architectures;
5. publishes only after both smoke tests pass.

Recommended Release title:

`From Here v1.1.0 — Listening Judgment`

Use [`RELEASE-v1.1.0.md`](RELEASE-v1.1.0.md) as the GitHub Release body.

Attach:

- `From-Here-v1.1.0-macOS.zip`
- `SHA256SUMS.txt`

GitHub's autogenerated Source archives remain for developers. The tested macOS asset is the one normal users should download.
