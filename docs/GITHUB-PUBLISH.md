## Release structure

Create tag:

`v1.0.0`

Build the user-facing asset with:

```bash
./scripts/build-release.sh
```

Recommended Release title:

`From Here v1.0.0 — First public release`

Use the copy in [`RELEASE-v1.0.0.md`](RELEASE-v1.0.0.md) as the GitHub Release body.

Attach:

`From-Here-v1.0.0-macOS.zip`

GitHub's autogenerated Source archives remain for developers. The macOS asset is the one normal users should download.
