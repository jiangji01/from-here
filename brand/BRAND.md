# From Here — Identity

## Core idea

**Origin → Path → Possibility.**

The mark is an open disc: part record, part origin, part exit. The circle is deliberately incomplete because the current song is not a closed label; it is a place to leave from.

## Visual language

- `#1238C8` — From Here Blue. Control, path, origin.
- `#171716` — Carbon. Typography and structural contrast.
- `#F3F0E8` — Warm Paper. Main surface.
- Album artwork may tint the atmosphere with a very low-opacity blur, but never replaces the brand color.
- Avoid generic AI gradients, sparkle icons, waveform clichés, glass dashboards, and dense card stacks.

## UI rule

**The song determines the air. From Here determines the skeleton.**

The primary interaction is a path, not a parameter slider. During a Session, the interface is a vertical route:

`origin → you are here → next`

## Small icon rule

At 16px, recognition wins over conceptual detail. Use the cobalt rounded tile with a heavy warm-paper open disc, center dot, and short outgoing path. Do not use the outline-only brand mark as the Chrome toolbar icon.
